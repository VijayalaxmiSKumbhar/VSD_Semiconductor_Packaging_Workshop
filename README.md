# Module 1 - Packaging Evolution: From Basics to 3D Integration

## L1: Introduction to Semiconductor Packaging and Industry Overview

* Why is Semiconductor Packaging is needed?

` Packaging can be viewed as the process of giving functionality, protection, and connectivity to a fabricated semiconductor die, enabling its successful operation in real-world electronic systems.`

* Example of semiconductor packaging is `Ball Grid Array (BGA)`

* The package consists of key elements such as:
  `die`, `die attach material`, `wire bonds`, `molding compound`, `substrate`, and `solder balls`.
  
The **die** provides the core functionality of the integrated circuit. The **die attach material** and **molding compound** provide mechanical support and protection from environmental and physical damage. **Wire bonds** and the **substrate** establish electrical interconnections for signal and power routing. **Solder balls** create the interface between the package and the printed circuit board (PCB), enabling communication with the external system.
